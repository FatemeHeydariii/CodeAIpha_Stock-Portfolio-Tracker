# Stock Portfolio Tracker

A simple Python program that calculates the total investment value of selected stocks.

## Features

- Uses a dictionary to store stock prices.
- Takes stock names and quantities from the user.
- Calculates the investment value for each stock.
- Calculates the total investment value.
- Optionally saves the result to a .txt file.
